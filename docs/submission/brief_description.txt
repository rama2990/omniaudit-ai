OmniAudit AI is an audit co-pilot for property developers that run each project as a separate company (SPV). It checks contractor bills before payment and matches buyer bank transfers to their units. Gemini 2.5 Flash on Vertex AI classifies each page and extracts fields as schema-validated JSON; every value must point to a word found by local OCR, so invented values are rejected. Deterministic code then computes VAT, construction withholding tax, retention, down-payment recoupment and late penalties, and runs eight checks such as overbilling and duplicate invoices across SPVs. Auditors review in a split view with highlighted evidence; the CFO approves large or suspicious cases. It runs as one container on Google Cloud Run (Jakarta, always-on CPU), calls Vertex AI with its service account, and mirrors the hash-chained audit trail and ERP journals to Firestore. Tested live: 15/15 scenario steps and 77 automated tests.
