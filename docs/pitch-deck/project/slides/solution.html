Who does what

1. Read

Gemini + local OCR

Recognizes invoices, inspection reports, tax invoices and photos. Every value must point to a word in the document; anything it can’t locate counts as uncertain.

2. Calculate

Deterministic code

VAT, construction withholding tax, retention, down payment, penalties, match scores and balanced journals. Exact decimals, repeatable and auditable.

3. Decide

Auditors and CFO

Clean bills are approved in one click. Suspicious ones are locked and opened in a split view. Every override needs a reason and is logged.

AI never calculates money. That’s what makes the result defensible to an external auditor.

This is the core of the design. Gemini only reads and points to where each value sits in the original document. If a value the AI reports isn’t in the document text, the system drops its confidence to zero, so a hallucination can’t reach the calculation. All money is computed by ordinary code with exact decimals. People decide, and every decision is logged.
