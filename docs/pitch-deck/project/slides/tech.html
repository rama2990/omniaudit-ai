Dibangun di atas Google

Gemini

Klasifikasi halaman dan ekstraksi field dengan output JSON terstruktur, lewat Google AI Studio.

Cloud Run

Satu container berisi API dan aplikasi web, region Jakarta; API key di Secret Manager.

Siap Vertex AI

Pindah ke Vertex AI asia-southeast2 cukup lewat konfigurasi, agar dokumen keuangan tetap di Indonesia.

OCR lokal

PyMuPDF untuk PDF digital, RapidOCR (model PaddleOCR) untuk hasil scan; gambar dokumen tidak keluar server.

FastAPI + React

Mesin hitung Python dengan Decimal, antarmuka Material UI berbahasa Indonesia.

Tahan gangguan

Kuota habis atau jaringan putus: dokumen tetap dibaca pola teks lokal, dengan pemberitahuan.

Gemini membaca dokumen dengan output JSON yang skemanya kita tentukan, jadi hasilnya bisa divalidasi. Aplikasi berjalan sebagai satu container di Cloud Run region Jakarta dengan API key di Secret Manager. Untuk produksi, cukup ubah konfigurasi ke Vertex AI di asia-southeast2 agar data keuangan tidak keluar Indonesia. OCR berjalan lokal sehingga gambar dokumen tidak dikirim ke luar.
