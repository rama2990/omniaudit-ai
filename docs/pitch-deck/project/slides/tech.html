Gemini 2.5 Flash on Vertex AI reads documents and returns JSON in a schema we define, so the output can be validated. The app runs as a single container on Cloud Run in the Jakarta region and calls Vertex AI with its own service account, so there is no API key on the server. Today the model is served from the global endpoint; for production we pin a regional endpoint so financial documents stay in-country. OCR runs locally, so page images are never sent out.
